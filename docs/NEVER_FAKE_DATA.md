# 🚫 JAMAIS DE FAUSSES DONNÉES

## RÈGLE ABSOLUE
**NE JAMAIS CRÉER, SIMULER OU GÉNÉRER DE FAUSSES DONNÉES**

### ❌ INTERDIT
- Générer des coordonnées aléatoires
- Créer des polygones simulés
- Inventer des références cadastrales
- Simuler des surfaces
- Utiliser des données de test

### ✅ OBLIGATOIRE
- Récupérer les vraies données depuis les APIs officielles
- Utiliser uniquement des données réelles existantes
- Documenter les sources de données
- Vérifier l'authenticité des données

### SOURCES OFFICIELLES À UTILISER
1. **Cadastre espagnol officiel** : https://ovc.catastro.meh.es/
2. **WFS/WMS officiels** : https://ovc.catastro.meh.es/Cartografia/
3. **CatastRo R package** : https://ropenspain.github.io/CatastRo/
4. **Données existantes** dans le projet (fincas_with_abandon_scores.geojson)

### EN CAS D'ÉCHEC DES APIs
- Documenter l'échec
- Chercher des alternatives officielles
- Demander au client des sources supplémentaires
- NE PAS créer de données simulées
